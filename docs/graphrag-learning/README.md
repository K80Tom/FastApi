# GraphRAG 新手学习导航

这套文档适合已经听过 RAG、向量数据库、知识库问答，但基础还不够稳的人。阅读顺序是从普通 RAG 开始，再逐步进入知识图谱、GraphRAG 索引、实体关系抽取、图存储、检索流程和项目落地。

现在这套文档分成两层：

```text
基础层：00-10，先把 GraphRAG 的主干讲明白。
进阶层：11-16，继续深入实体消歧、社区摘要、检索编排、评估调优和 FastAPI 工程落地。
```

建议不要跳读。GraphRAG 最容易卡住的地方不是代码，而是没有想清楚：

```text
为什么普通 RAG 不够？
为什么要把文档变成图？
图上的实体、关系、社区到底在检索时怎么用？
```

## 学习节奏建议

如果你每天只有 1 小时，可以这样安排：

```text
第 1 天：读 00 和 01，搞清普通 RAG 的问题
第 2 天：读 02，理解实体、关系、图
第 3 天：读 03，理解 GraphRAG 为什么需要图
第 4 天：读 04 和 05，理解数据怎么从文档变成图
第 5 天：读 06，知道图数据怎么存
第 6 天：读 07 和 08，理解全局检索、局部检索、混合检索
第 7 天：读 09 和 10，整理成一个可展示项目和表达稿
```

如果你觉得基础层偏简单，可以继续用 6 天读进阶层：

```text
第 8 天：读 11，理解 GraphRAG 真正难在哪里
第 9 天：读 12，理解实体消歧、alias、关系去重
第 10 天：读 13，理解社区发现和社区摘要
第 11 天：读 14，理解多路召回、重排、上下文预算
第 12 天：读 15，理解怎么评估和调优 GraphRAG
第 13 天：读 16，把 GraphRAG 接到 FastAPI 项目结构
```

## 最终建议做的项目

建议最后做一个：

```text
企业知识库 GraphRAG 问答系统
```

最小版本功能：

- 上传 Markdown / TXT 文档。
- 切分文档 chunk。
- 抽取实体和关系。
- 保存实体、关系、chunk、向量。
- 支持普通向量检索。
- 支持基于实体的局部检索。
- 支持基于社区摘要的全局检索。
- 用 FastAPI 暴露 `/ask`、`/ask/local`、`/ask/global` 接口。
- 返回答案时带引用来源。

学完这套文档后，你不一定马上能写出工业级 GraphRAG，但应该能说清楚它的核心思想，并能做出一个小而完整的演示项目。

进阶层学完后，你应该还能继续回答：

```text
实体重复怎么办？
关系抽错怎么办？
社区摘要怎么影响全局检索？
上下文太长怎么裁剪？
GraphRAG 怎么评估？
FastAPI 项目里 endpoint、service、repository 怎么分层？
```
