# Docker 学习资料

这套资料面向零基础学习者，目标是让你从"不知道 Docker 是什么"走到"能在真实项目中用 Docker 跑服务、写 Dockerfile、用 Compose 编排多容器"。

建议阅读顺序：

```text
00_学习总路线.md
01_Docker是什么与为什么需要它.md
02_安装Docker与环境配置.md
03_Docker核心概念_镜像容器仓库.md
04_第一个容器_HelloWorld.md
05_常用Docker命令速查.md
06_镜像详解与镜像分层.md
07_Dockerfile编写与镜像构建.md
08_容器数据持久化_Volume.md
09_Docker网络详解.md
10_Docker_Compose入门.md
11_Docker_Compose进阶.md
12_镜像仓库与分发.md
13_多阶段构建与镜像优化.md
14_常见报错与排查.md
15_Docker在开发中的实践.md
16_Docker进阶与生产实践.md
```

每个文件都能单独阅读，也能连成完整学习体系。建议先按 `00_学习总路线.md` 的 7 天计划快速跑一遍，再用 14 天计划补扎实。

阅读建议：主线 00→12 按顺序走；`14_常见报错` 遇到问题时随时翻；`13` 和 `15`、`16` 是进阶篇，在跑通基础流程后再看。
