## Day 1（周一）：读懂PG表结构

**上午：**
- 连上公司的 PG 数据库（拿到连接信息）
- 用 `\dt` 列出所有表，用 `\d table_name` 看每张表的结构
- 画出7张表的关系图（纸上或 mermaid）

**下午：**
- 写5条SQL练习：
  ```sql
  -- 1. 查所有角色资产
  SELECT * FROM asset_entities WHERE asset_kind = 'character' LIMIT 20;
  -- 2. 查某个资产的所有媒体文件
  SELECT * FROM asset_media WHERE asset_id = 'xxx';
  -- 3. JOIN：角色+图片
  SELECT e.name, m.url FROM asset_entities e JOIN asset_media m ON m.asset_id = e.id;
  -- 4. 统计各类型数量
  SELECT asset_kind, COUNT(*) FROM asset_entities GROUP BY asset_kind;
  -- 5. 某项目下的所有资产
  SELECT e.* FROM project_asset_refs r JOIN asset_entities e ON e.id = r.asset_id WHERE r.project_id = 'xxx';
  ```

**产出：** 表关系图 + 5条SQL验证通过

## Day 3（周三）：设计你的 Milvus Schema + 字段分析

**上午：**
- 对照公司的7张表，逐个分析每个字段：
  - 适合转向量？（有语义的文本：name, description, prompt_text）
  - 适合做metadata？（asset_kind, source_project_id）
  - 只留PG？（id, created_at, storage_path）
- 写出分析文档（参考 03_入库方案设计与实现.md）

**下午：**
- 设计正式的 Milvus Collection Schema：
  ```python
  fields = [
      FieldSchema("id", DataType.INT64, is_primary=True, auto_id=True),
      FieldSchema("vector", DataType.FLOAT_VECTOR, dim=1536),
      FieldSchema("source_table", DataType.VARCHAR, max_length=64),
      FieldSchema("source_id", DataType.VARCHAR, max_length=64),
      FieldSchema("asset_kind", DataType.VARCHAR, max_length=32),
      FieldSchema("source_project_id", DataType.VARCHAR, max_length=64),
      FieldSchema("name", DataType.VARCHAR, max_length=256),
      FieldSchema("text", DataType.VARCHAR, max_length=2048),
  ]
  ```
- 创建正式的 Collection 并建好索引

**产出：** 字段分析文档 + 正式Collection已创建

## Day 5（周五）：实现搜索验证

**上午：**
- 写搜索函数：query → embedding → Milvus search → 打印结果
- 测试几个搜索词，验证语义匹配是否合理：
  ```python
  search("古风仙女")       # 应该找到古风女性角色
  search("现代都市场景")    # 应该找到现代背景的场景
  search("打斗动作")       # 应该找到动作相关的分镜
  ```
- 调整：如果效果不好，检查 embedding_text 的拼接是否合理

**下午：**
- 实现回查PG：Milvus返回source_id → 批量查PG → 拼装完整结果
- 写一个简单的搜索API函数（不需要Web框架，先CLI验证）：
  ```python
  results = search_assets("古风仙女", asset_kind="character", top_k=5)
  for r in results:
      print(f"{r['name']} - {r['description'][:50]} - score:{r['score']:.3f}")
  ```

**产出：** 搜索可用，能返回合理的语义匹配结果
