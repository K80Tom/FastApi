# 附录D 术语速查表 + 学习进度自查清单

## 1. 这一节要解决什么问题

给你一张随时回查的术语总表，看任何文件遇到不懂的词都能在这里秒查；再给你一套可打勾的进度清单，配合 7/14/30 天计划，让基础差的你每天都有看得见的正反馈。

## 2. 怎么用这一节

通俗解释：术语表当字典用，进度表当打卡本用。不用从头读，哪里卡了翻哪里。

例子：你在 06 节看到“double quant”不懂，翻到下面术语表“量化相关”一栏即可；学完 05 节，回到进度表把对应方框打勾。

## 3. 为什么要学这个

基础差的人最容易因为“一个词不懂”就卡住、放弃。一张总表降低查找成本；一份打勾清单提供持续成就感，这对长期坚持比任何技巧都重要。

## 4. 术语速查表

### 4.1 训练范式

| 术语 | 一句话解释 | 生活类比 |
| --- | --- | --- |
| Pretraining 预训练 | 用海量数据训练出有通用能力的基础模型 | 从小读到大学 |
| Post-training 后训练 | 预训练之后的所有训练统称 | 毕业后的职场培训 |
| Fine-tuning 微调 | 在已有模型上用特定数据继续训练 | 老厨师专攻一个菜系 |
| Continue Pretraining 继续预训练 | 用大量领域无标注文本继续“喂书” | 进修读更多专业书 |
| Instruction tuning 指令微调 | 教模型听懂并执行指令 | 教会按要求办事 |
| SFT 监督微调 | 用“问题+标准答案”对训练 | 看着标准答案模仿 |
| RLHF 人类反馈强化学习 | 用人类偏好打分来优化模型 | 师傅点评好坏来调教 |
| DPO 直接偏好优化 | 不用强化学习，直接用“好答案 vs 坏答案”对优化 | 二选一告诉它该学哪个 |

### 4.2 高效微调方法

| 术语 | 一句话解释 | 生活类比 |
| --- | --- | --- |
| Full Fine-tuning 全量微调 | 更新模型全部参数，成本最高 | 重写整本教材 |
| PEFT 参数高效微调 | 只训练一小部分参数的方法统称 | 只改关键几页 |
| LoRA | 冻结原模型，只训练新增低秩矩阵 | 教材旁贴便签 |
| QLoRA | 在 4bit 量化模型上做 LoRA | 压缩教材再贴便签 |
| Adapter | 在层间插入小模块只训练它 | 加装小插件 |
| Merge LoRA | 把 LoRA 权重合并回基础模型 | 把便签抄进教材 |

### 4.3 数据相关

| 术语 | 一句话解释 | 生活类比 |
| --- | --- | --- |
| Tokenizer 分词器 | 把文字切成模型能读的编号 | 把句子切成积木块 |
| Token | 模型处理的最小文本单位 | 一块积木 |
| Dataset 数据集 | 训练用的样例集合 | 练习册 |
| JSONL | 一行一条 JSON 样例的格式 | 一行一张卡片 |
| Alpaca 格式 | instruction/input/output 单轮格式 | 简单问答卡 |
| ShareGPT 格式 | conversations/from/value 多轮格式 | 聊天记录本 |
| messages 格式 | role/content 的 API 风格格式 | 标准对话剧本 |
| Epoch | 把整个数据集完整训练一遍 | 把练习册做完一遍 |

### 4.4 训练参数

| 术语 | 一句话解释 | 生活类比 |
| --- | --- | --- |
| Batch size | 一次喂给模型多少条样例 | 一口吃几个 |
| Gradient accumulation 梯度累积 | 攒几个小 batch 再更新，等效放大 batch | 攒够几口再咽 |
| Learning rate 学习率 | 每次调整参数的步子大小 | 改作业改多狠 |
| Loss 损失 | 衡量预测和答案差距的数字，越小越拟合 | 错题扣分 |
| Checkpoint 检查点 | 训练中途保存的模型存档 | 游戏存档 |
| max_seq_length | 单条样本最大 token 长度 | 一次最多读多长 |

### 4.5 量化与部署

| 术语 | 一句话解释 | 生活类比 |
| --- | --- | --- |
| Quantization 量化 | 用低精度存权重，省显存 | 高清图压缩成小图 |
| nf4 | QLoRA 推荐的 4bit 量化类型 | 一种压缩算法 |
| Double quant 双重量化 | 对量化参数再量化，再省一点 | 压缩包再压一次 |
| Inference 推理 | 用训练好的模型生成回答 | 正式答题 |
| Overfitting 过拟合 | 背熟训练集但换题就不会 | 死记答案 |
| Evaluation 评估 | 用测试题量化模型好坏 | 期末考试 |
| vLLM | 高性能推理部署框架 | 高速出餐窗口 |
| Ollama | 本地一键跑模型的工具 | 家用小厨房 |
| API 部署 | 把模型包成接口供调用 | 开个点餐热线 |

注意事项：术语第一次在正文出现都有详细类比解释，这张表只是快速回忆用。记不清就回对应章节看完整版。

## 8. 常见误区

1. 误区：术语表背下来就懂微调了。  
   解释：术语是入口，理解要靠正文的例子和动手跑代码。

2. 误区：进度必须一字不差按计划走。  
   解释：难的章节拆成两三天很正常，清单是帮你不漏项，不是考勤。

3. 误区：没全勾上不能往下学。  
   解释：可以先标记卡点继续推进，回头再补，避免在一个点上彻底卡死。
