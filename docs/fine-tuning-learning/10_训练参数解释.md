# 10 训练参数解释

## 1. 这一节要解决什么问题

这一节帮你看懂微调配置里的 epoch、batch size、learning rate、gradient accumulation、sequence length 等参数，并知道新手该如何安全调整。

## 2. 基础概念解释

### Epoch 训练轮数

通俗解释：epoch 像把整本练习册完整做几遍。做 3 个 epoch，就是练习册从头到尾做 3 遍。

技术解释：Epoch 表示训练算法完整遍历训练集的次数。

例子：训练集 1000 条，`num_train_epochs=3` 表示总共看过 3000 条样本次。

### Batch size 批大小

通俗解释：batch size 像老师一次批改几道题。一次批太多，桌子摆不下；一次批太少，速度慢。

技术解释：Batch size 是每次前向和反向传播使用的样本数量。

例子：`per_device_train_batch_size=2` 表示每张 GPU 一次处理 2 条样本。

### Learning rate 学习率

通俗解释：learning rate 像每次改错时改多大步。步子太大容易改过头，步子太小进步慢。

技术解释：Learning rate 控制优化器每次更新参数的幅度。

例子：LoRA 微调常见学习率可能在 `1e-4` 到 `2e-4`，DPO 可能更小，例如 `5e-5`。

### Gradient accumulation 梯度累积

通俗解释：显存小的时候，老师一次只能批 1 道题，但可以批 4 次后一起总结，相当于一次看了 4 道题。

技术解释：Gradient accumulation 是多次小 batch 计算梯度后再更新一次参数，用较小显存模拟较大 batch。

例子：`batch_size=1`、`gradient_accumulation_steps=4`，等效 batch 大约是 4。

### Sequence length 序列长度

通俗解释：sequence length 像每道题允许的最大字数。字数越多，读题越费空间和时间。

技术解释：Sequence length 是模型一次处理的最大 token 数。

例子：`max_seq_length=512` 比 `2048` 更省显存，但可能截断长回答。

## 3. 为什么要学这个

训练参数决定微调能不能跑、是否稳定、是否过拟合、需要多少显存。你不用一开始懂所有参数，但必须掌握几个“旋钮”：batch size、learning rate、epoch、sequence length、gradient accumulation。

## 4. 关键知识点

### 4.1 参数优先级

解释：新手先关注最影响训练成败的参数。

例子：

| 优先级 | 参数 | 影响 |
| --- | --- | --- |
| 高 | batch size | 显存、稳定性 |
| 高 | learning rate | 是否发散、收敛速度 |
| 高 | epoch | 是否训练不够或过拟合 |
| 高 | max_seq_length | 显存、是否截断 |
| 中 | gradient_accumulation | 等效 batch |
| 中 | warmup_ratio | 前期稳定 |
| 中 | weight_decay | 正则化 |
| 低 | logging_steps、save_steps | 观察和保存频率 |

注意事项：不要被几十个参数吓住。先掌握前五个就能跑很多小实验。

### 4.2 Batch size 和显存

解释：batch size 越大，一次放进显存的样本越多，显存占用越高。

例子：如果 `batch_size=2` 爆显存，先改成 `1`，再用 `gradient_accumulation_steps=4` 保持训练稳定性。

注意事项：小 batch 训练可能更不稳定，所以需要观察 loss。

### 4.3 Learning rate 怎么选

解释：学习率太高可能 loss 爆炸，太低可能训练很久没有变化。

例子：

```text
LoRA SFT 初始可试：2e-4 或 1e-4
QLoRA SFT 初始可试：2e-4
DPO 初始可试：5e-5 或 1e-5
```

注意事项：这些不是固定真理，只是初学起点。具体要看模型、数据和任务。

### 4.4 Epoch 怎么选

解释：数据少时 epoch 过多容易过拟合，数据多时 epoch 太少可能学不够。

例子：几百条小数据可以先试 1 到 3 个 epoch，然后看验证集效果。

注意事项：不要只看训练 loss。训练 loss 一直下降，但验证效果变差，就是过拟合信号。

### 4.5 Gradient accumulation 怎么算

解释：等效 batch size 约等于每卡 batch size 乘以梯度累积步数再乘以 GPU 数量。

例子：

```text
1 张 GPU
per_device_train_batch_size = 1
gradient_accumulation_steps = 8
等效 batch size = 8
```

注意事项：梯度累积会让一次参数更新变慢，但能降低显存压力。

### 4.6 保存和日志参数

解释：保存太频繁会占磁盘，保存太少可能错过好 checkpoint。

例子：

```python
logging_steps=10
save_steps=200
eval_steps=200
save_total_limit=3
```

注意事项：小实验可以保存频繁一点，大训练要控制磁盘空间。

### 4.7 新手推荐配置

解释：先用保守配置跑通，再慢慢调。

例子：

```python
TrainingArguments(
    output_dir="./outputs/run1",
    per_device_train_batch_size=1,
    gradient_accumulation_steps=4,
    learning_rate=2e-4,
    num_train_epochs=2,
    logging_steps=10,
    save_steps=200,
    fp16=True,
)
```

注意事项：如果 GPU 支持 bf16，可以考虑 `bf16=True`，但不要同时乱开 fp16 和 bf16。

## 8. 常见误区

1. 误区：batch size 越大越好。  
   解释：过大会爆显存，也不一定带来更好效果。

2. 误区：learning rate 越小越稳，所以越小越好。  
   解释：太小可能几乎学不动。

3. 误区：epoch 越多模型越聪明。  
   解释：过多 epoch 可能让模型背训练集。

4. 误区：显存不够只能换显卡。  
   解释：可以先降 batch、降序列长度、用 QLoRA、减小 LoRA r。

## 9. 本节总结

训练参数是微调项目的控制面板。新手先掌握 epoch、batch size、learning rate、gradient accumulation 和 max_seq_length。每次只改一个关键参数，并通过日志和评估观察效果。
